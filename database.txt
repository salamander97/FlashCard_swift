# 🌸 Japanese Learning Website - Database Documentation

## Tổng quan Database

**Database Engine:** PostgreSQL  
**Character Set:** UTF-8 (hỗ trợ tiếng Nhật)  
**Database Name:** `japanese_learning`  
**Connection:** Host: localhost, Port: 5432

---

## 📊 Kiến trúc Database

### 1. **Core Tables** (Bảng chính)
- `users` - Quản lý người dùng
- `user_progress` - Tiến độ học tập tổng quát
- `user_activities` - Lịch sử hoạt động học tập
- `quiz_sessions` - Phiên làm bài quiz

### 2. **Vocabulary System Tables** (Hệ thống từ vựng)
- `vocabulary_categories` - Danh mục từ vựng (20 chủ đề)
- `vocabulary_words` - Từ vựng chi tiết
- `user_category_progress` - Tiến độ theo từng chủ đề
- `user_word_knowledge` - Kiến thức từng từ (SRS Algorithm)

### 3. **Achievement Tables** (Hệ thống thành tích)
- `user_achievements` - Thành tích đạt được

## 🗃️ Chi tiết các bảng

### 📋 Table: `users`
**Mục đích:** Quản lý thông tin người dùng

```sql
CREATE TABLE users (
    id SERIAL PRIMARY KEY,
    username VARCHAR(50) UNIQUE NOT NULL,
    email VARCHAR(100) UNIQUE,
    password_hash VARCHAR(255) NOT NULL,
    display_name VARCHAR(100),
    is_active BOOLEAN DEFAULT TRUE,
    created_at TIMESTAMP WITH TIME ZONE DEFAULT NOW(),
    updated_at TIMESTAMP WITH TIME ZONE DEFAULT NOW(),
    last_login TIMESTAMP WITH TIME ZONE
);
```

**Indexes:**
- `users_username_idx` - Unique index trên username
- `users_email_idx` - Unique index trên email

**Sample Data:**
```sql

(2, 'student1', 'student1@example.com', '$2y$10$...', 'Học sinh 1', true, NOW(), NOW(), NULL);
```

### 📈 Table: `user_progress`
**Mục đích:** Tracking tiến độ học tập tổng quát của user

```sql
CREATE TABLE user_progress (
    id SERIAL PRIMARY KEY,
    user_id INTEGER UNIQUE REFERENCES users(id) ON DELETE CASCADE,
    
    -- Hiragana Progress
    hiragana_score INTEGER DEFAULT 0,
    hiragana_total INTEGER DEFAULT 0,
    
    -- Katakana Progress  
    katakana_score INTEGER DEFAULT 0,
    katakana_total INTEGER DEFAULT 0,
    
    -- Numbers Progress
    numbers_score INTEGER DEFAULT 0,
    numbers_total INTEGER DEFAULT 0,
    
    -- Legacy Vocabulary (sẽ deprecated)
    vocabulary_n5_score INTEGER DEFAULT 0,
    vocabulary_n5_total INTEGER DEFAULT 0,
    vocabulary_n4_score INTEGER DEFAULT 0,
    vocabulary_n4_total INTEGER DEFAULT 0,
    vocabulary_n3_score INTEGER DEFAULT 0,
    vocabulary_n3_total INTEGER DEFAULT 0,
    
    -- New Vocabulary System
    vocabulary_categories_unlocked INTEGER DEFAULT 2,
    vocabulary_words_learned INTEGER DEFAULT 0,
    vocabulary_words_mastered INTEGER DEFAULT 0,
    vocabulary_total_score INTEGER DEFAULT 0,
    vocabulary_study_time INTEGER DEFAULT 0, -- seconds
    
    created_at TIMESTAMP WITH TIME ZONE DEFAULT NOW(),
    last_updated TIMESTAMP WITH TIME ZONE DEFAULT NOW(),
    updated_at TIMESTAMP WITH TIME ZONE DEFAULT NOW(),
    
    -- Constraints
    CONSTRAINT chk_hiragana_score CHECK (
        hiragana_score >= 0 AND 
        (hiragana_total = 0 OR hiragana_score <= hiragana_total)
    ),
    CONSTRAINT chk_katakana_score CHECK (
        katakana_score >= 0 AND 
        (katakana_total = 0 OR katakana_score <= katakana_total)
    ),
    CONSTRAINT chk_numbers_score CHECK (
        numbers_score >= 0 AND 
        (numbers_total = 0 OR numbers_score <= numbers_total)
    )
);
```

**Triggers:**
- `update_user_progress_updated_at` - Auto update timestamp

**Sample Data:**

```sql
CREATE TABLE vocabulary_categories (
```

### 🧠 Table: `user_word_knowledge` (SRS Algorithm)
**Mục đích:** Spaced Repetition System cho từng từ

```sql
CREATE TABLE user_word_knowledge (
    id SERIAL PRIMARY KEY,
    user_id INTEGER REFERENCES users(id) ON DELETE CASCADE,
    word_id INTEGER REFERENCES vocabulary_words(id) ON DELETE CASCADE,
    
    -- SRS Algorithm Fields
    knowledge_level INTEGER DEFAULT 0,     -- 0=new, 1-10=learning levels
    ease_factor DECIMAL(3,2) DEFAULT 2.50, -- 1.30-4.00, how easy the word is
    interval_days INTEGER DEFAULT 0,       -- days until next review
    next_review_date TIMESTAMP WITH TIME ZONE DEFAULT NOW(),
    
    -- Statistics
    total_reviews INTEGER DEFAULT 0,
    correct_reviews INTEGER DEFAULT 0,
    incorrect_reviews INTEGER DEFAULT 0,
    consecutive_correct INTEGER DEFAULT 0,
    
    -- Learning State
    difficulty_level VARCHAR(20) DEFAULT 'new', -- 'new', 'learning', 'mature'
    first_learned_at TIMESTAMP WITH TIME ZONE,
    last_reviewed_at TIMESTAMP WITH TIME ZONE,
    
    created_at TIMESTAMP WITH TIME ZONE DEFAULT NOW(),
    updated_at TIMESTAMP WITH TIME ZONE DEFAULT NOW(),
    
    UNIQUE(user_id, word_id)
);
```

**SRS Algorithm Logic:**
- **New words:** `knowledge_level = 0`, review ngay
- **Learning:** `knowledge_level 1-6`, interval tăng dần (1, 3, 7, 14, 30, 60 days)
- **Mature:** `knowledge_level 7+`, interval 120+ days
- **Ease Factor:** Giảm khi trả lời sai, tăng khi liên tiếp đúng

## 🔧 Functions & Triggers

### Function: `calculate_learning_streak()`
```sql
CREATE OR REPLACE FUNCTION calculate_learning_streak(p_user_id INTEGER) 
RETURNS INTEGER AS $$
DECLARE
    streak INTEGER := 0;
    current_date DATE := CURRENT_DATE;
    activity_dates DATE[];
    i INTEGER;
BEGIN
    -- Lấy danh sách các ngày có hoạt động
    SELECT ARRAY_AGG(DISTINCT DATE(created_at) ORDER BY DATE(created_at) DESC)
    INTO activity_dates
    FROM user_activities
    WHERE user_id = p_user_id;
    
    -- Kiểm tra streak từ ngày hiện tại
    FOR i IN 1..COALESCE(array_length(activity_dates, 1), 0) LOOP
        IF activity_dates[i] = current_date - INTERVAL '1 day' * (i - 1) THEN
            streak := streak + 1;
        ELSE
            EXIT;
        END IF;
    END LOOP;
    
    RETURN streak;
END;
$$ LANGUAGE plpgsql;
```

### Trigger: Auto Update Timestamps
```sql
CREATE OR REPLACE FUNCTION update_updated_at_column()
RETURNS TRIGGER AS $$
BEGIN
    NEW.updated_at = NOW();
    RETURN NEW;
END;
$$ LANGUAGE plpgsql;

-- Apply cho các bảng cần
CREATE TRIGGER update_users_updated_at 
    BEFORE UPDATE ON users 
    FOR EACH ROW EXECUTE PROCEDURE update_updated_at_column();
```

## 🚀 Query Examples

### 1. Lấy tiến độ tổng quát của user
```sql
SELECT 
    u.username,
    u.display_name,
    up.hiragana_score,
    up.hiragana_total,
    ROUND(up.hiragana_score::DECIMAL / NULLIF(up.hiragana_total, 0) * 100, 1) as hiragana_percentage,
    up.vocabulary_words_learned,
    up.vocabulary_words_mastered
FROM users u
JOIN user_progress up ON u.id = up.user_id
WHERE u.id = $1;
```

### 2. Lấy từ cần ôn tập (SRS)
```sql
SELECT 
    vw.id,
    vw.japanese_word,
    vw.kanji,
    vw.vietnamese_meaning,
    uwk.knowledge_level,
    uwk.next_review_date
FROM user_word_knowledge uwk
JOIN vocabulary_words vw ON uwk.word_id = vw.id
WHERE uwk.user_id = $1 
    AND uwk.next_review_date <= NOW()
    AND vw.is_active = true
ORDER BY uwk.next_review_date ASC
LIMIT 20;
```

### 3. Thống kê học tập theo tháng
```sql
SELECT 
    DATE_TRUNC('month', created_at) as month,
    activity_type,
    COUNT(*) as total_sessions,
    AVG(score::DECIMAL / NULLIF(total_questions, 0) * 100) as avg_percentage
FROM user_activities
WHERE user_id = $1 
    AND created_at >= NOW() - INTERVAL '6 months'
GROUP BY DATE_TRUNC('month', created_at), activity_type
ORDER BY month DESC, activity_type;
```

## 📋 Data Maintenance

### Weekly Cleanup Tasks
```sql
-- Xóa sessions chưa hoàn thành cũ hơn 24h
DELETE FROM quiz_sessions 
WHERE is_completed = false 
    AND created_at < NOW() - INTERVAL '24 hours';

-- Update completion percentages
UPDATE user_category_progress 
SET completion_percentage = (
    learned_words::DECIMAL / NULLIF(total_words, 0) * 100
);
```
